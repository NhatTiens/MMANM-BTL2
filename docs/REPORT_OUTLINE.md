# Dàn ý báo cáo kỹ thuật (20–30 trang)
Đề bài yêu cầu 4 chương, trọng tâm chương 2–3. Đây là dàn ý, chưa có kết quả thực nghiệm.

1. Giới thiệu (2–3 trang): mục tiêu, yêu cầu đề 2.1/2.2, phạm vi và môi trường, đóng góp thành viên.
2. Phân tích và thiết kế (7–9 trang): mô hình threat, segmentation, IP theo MSSV, firewall matrix, VPN, TLS/BTL1, IDS/IPS, log schema, dashboard, sơ đồ luồng. Phụ trách 1+2+3+4 theo module.
3. Hiện thực và đánh giá (10–13 trang): môi trường/phiên bản, cấu hình thực, test matrix, rule MSSV, 5 nhóm detection, IPS, VPN, dashboard, kết quả đo latency/throughput/FP/FN; chèn ảnh thật và giải thích hạn chế.
4. Kết luận (2–3 trang): đạt/chưa đạt theo yêu cầu, ưu nhược điểm, hướng phát triển.
Tài liệu tham khảo, phụ lục môi trường/thư viện, bảng đóng góp và hướng dẫn tái lập. Điều chỉnh số trang để tổng 20–30 theo đề.
